# Airdrop to iPhone

A native Finder action for sending selected files to a designated iPhone.

## How to use

1. Select one or more files in Finder.
2. Right-click and choose **Airdrop to iPhone**.
3. Allow folder access if macOS asks. The helper selects your iPhone and sends the files automatically.

https://github.com/user-attachments/assets/d9e55265-c3d9-4763-921f-059428364070

The current build targets a device named **Ryan iPhone** and requires Accessibility access. Your phone must be available in AirDrop. The native AirDrop picker appears briefly while the helper selects it.
